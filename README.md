# Portfolio — Johana Falade

Portfolio personnel responsive présentant le parcours, les compétences, certificats et projets de Johana FALADE.

## Technologies

- **HTML5** — Structure sémantique
- **CSS3** — Design system custom avec variables CSS
- **Bootstrap 5.3** — Grid, composants, responsive
- **Bootstrap Icons** — Iconographie
- **JavaScript vanilla** — Animations, navigation, accessibilité
- **Google Fonts** — Inter (texte) + Bricolage Grotesque (titres)

## Fonctionnalités

- Hero section centrée avec badge pill animé
- Photo profil avec effet glassmorphism (backdrop-filter blur)
- Cards layout liste avec initiales colorées
- Timeline verticale pour le parcours
- Section contact avec fond sombre
- Scroll reveal animations (IntersectionObserver)
- Navigation responsive avec menu hamburger
- Accessibilité : skip link, focus-visible, prefers-reduced-motion
